## Тестовое задание на вёрстку карточки товара

Данный проект - это тестовое задание на вёрстку карточки товара. В папке `src/` он демонстрирует структуру файлов для генерации вёрстки, а также предоставляет билд для запуска вёрстки локально в папке `/dist.`

Код проекта хранится на github: https://github.com/Galch24/testtask-product-card-layout

## Запуск вёрстки локально
Для разворачивания сборки требуется запустить локально сервер из папки `/dist`.
Простое перетаскивание `/dist/index.html` в браузер покажет стили, но не покажет работу скриптов, так как браузеры из соображений безопасности не позволяют "инлайново" подгружать скрипты локальных html файлов.

Для просмотра сайта воспользуйтесь универсальным способом поднятия стенда.
1. Откройте терминал (на mac os) или командную строку (Windows).
2. В окне терминала перейдите в папку с файлом `/dist/index.html`
3. Запустите команду для запуска локального веб-сервера с помощью команды:
```
python3 -m http.server 8882
```
4. После запуска команды, - в браузере перейдите по адресу:
```
http://localhost:8882/
```

Откроется сайт из файла `/dist/index.html`

Важно!
Перед запуском команды для запуска локально веб-сервера убедитесь, что запускаете команду в папке с index.html.


### Запуск в режиме разработки

В папке `src/` приложены исходники, на базе которых подготовлен билд. А именно: 
 - файлы scss для стилей в css.
 - html код, разбитый на компоненты
 - скрипты javascript.

Для запуска в режиме разработки требуется запросить исходник config у автора сборки.
